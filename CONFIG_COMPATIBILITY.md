# Compatibility with uploaded DA/FC configurations (17 Aug 2026)

This compatibility record started from the supplied `configs.FC.tar` and
`configs.DA.tar`.  The PRM portion has now also been re-audited against the
latest uploaded `gocartMPAS-main.zip`; that source is authoritative for the
current plume-rise interface.

## Forecast streams actually consumed by MPAS-GOCART2G

The supplied forecast `streams.atmosphere` reads the following emissions.
`SetStreamsVariant.csh` in this package resolves the same names using the active
cycle year and `nCells`.

| Stream | MPAS variables | Control inventory/file family |
|---|---|---|
| anthropogenic BC | `bc_anth_res`, `bc_anth_sum` | CAMS BC |
| anthropogenic OC | `oc_anth_res`, `oc_anth_sum` | CAMS OC |
| anthropogenic NH3 | `nh3_anth_agl,ags,awb,ene,fef,ind,res,shp,slv,sum,swd,tnr,tro` | CAMS NH3 |
| anthropogenic SO2 | `so2_anth_sum` | CAMS SO2 |
| anthropogenic isoprene | `iso_anth_sum` | CAMS ISO |
| anthropogenic monoterpenes | `mnt_anth_sum` | CAMS MNT |
| anthropogenic CO | `co_anth_sum` | CAMS CO |
| biomass burning | `bc,oc,nh3,so2,co,iso,mnt_biob_modis` | shared FINNv2.5.1 annual hourly file |
| biogenic | `co,iso,mnt,mnta,mntb_biog_megan` | CAMS biogenic files |
| PRM fire properties | `firesize_biob_modis_avg`, `firesize_biob_modis_std`, `frp_biob_modis_avg`, `frp_biob_modis_std` | one separate FINNv2.5.1 daily fire-statistics file, exposed through four input streams |

The forecast namelist sets `config_gocart2G_biobemis_interval='00_01:00:00'`
and the PRM cadence to one day for fire-property LBCs.  v1.12 writes workflow-native FINN as (1) an hourly CDF-5 file containing all seven biomass-burning species and (2) a separate daily CDF-5 fire-statistics file containing AREA mean/std and FRP mean/std.

The staged forecast directory also contains CEDS/GFAS/QFED/CAMS-MIX products.
The current stream selector uses:

- CEDS: BC, OC, SO2, CO. CEDS NH3 is now intentionally selected with CEDS BC/OC/SO2/CO for members 4-6. The output must contain the full sector-resolved `nh3_anth_*` contract required by the current stream.
- GFAS: BC, OC, NH3, SO2, CO, ISO, MNT.
- QFED: BC, OC, NH3, SO2, CO; ISO/MNT fall back to FINN, matching the current
  run directory and selector.
- CAMS-MIX: BC, OC, SO2, CO; NH3 remains CAMS global until a regional-mix NH3 source is supplied; ISO/MNT remain CAMS.

Files that happen to be staged but are not referenced by the supplied streams
(e.g. anthropogenic NO2 and AEIM India files) are intentionally not required by
this package.

## DA configuration

The supplied DA `streams.atmosphere_60km` has no emissions input streams.  DA
reads background/analysis/ensemble/control state files.  Its 3D-hybrid state
includes BC, BrC, OC, dust, sea salt, sulfate and nitrate001-003, but not NH3 or
HNO3.  Thus emissions are a **forecast input**; DA sees their impact through the
forecast/background state rather than reading emissions files directly.

## Changes made after this check

v1.4 retains the v1.3 stream/PRM fixes and additionally:

1. selects CEDS NH3 whenever the anthropogenic member uses CEDS;
2. reads historical FINNv2.5/2.5.1 directly from verified GDEX d312009 holdings, including annual/monthly text containers;
3. adds source-first `PrepareChemIC` and a GOCART2G-enabled `init_atmosphere` path so raw MERRA chemistry, emissions, and prescribed backgrounds can initialize the model state;
4. makes missing required MERRA chemistry variables fatal by default and records raw-source provenance;
5. exposes independent HNO3/NH3/nitrate-bin scaling in chemistry initialization, separate from emission scaling;
6. retains CDF-5 for every MPAS-facing file generated by the new code.

## HNO3 versus emissions

There is **no HNO3 emissions stream in the supplied forecast configuration**.
HNO3 enters the nitrate system through chemical initialization/background/
nudging.  The emitted nitrogen precursor in these emissions streams is NH3.
For this reason v1.4 supports optional NH3 emission scaling and, separately, explicit HNO3 scaling in the raw MERRA/GMI chemistry-initialization pathway.

## v1.12 latest-model PRM correction

The latest MPAS-GOCART2G Registry exposes four lowbc streams:
`prm_lowbc_area_avg`, `prm_lowbc_area_std`, `prm_lowbc_frp_avg`, and
`prm_lowbc_frp_std`, with the current `config_prm_lowbc_interval` naming.

The PRM author subsequently clarified the runtime severity: **only
`prm_lowbc_area_avg` / `firesize_biob_modis_avg` is currently required**.
The other three inputs are optional and missing-data messages should be
warnings rather than errors. v1.12 therefore:

- keeps all four stream definitions in forecast and GOCART2G init templates;
- makes only fire-size average fatal in `validate_streams`;
- generates AREA std/FRP avg/std whenever source information is available;
- zero-fills unavailable optional fields in workflow-generated FINN PRM files
  and records warnings/provenance;
- accepts an existing AREA-average-only PRM file with warnings;
- uses the FINN MOZART AREA field when dedicated base_FRP is unavailable.

The uploaded 2024 MOZART and base_FRP samples each contain 40,905 records, and
their shared AREA/emissions fields match row-for-row, confirming the MOZART
fallback for the required fire-size mean.
